# Data Strategy

## Corpus (38 documents)

- **28 Markdown** files in `documents/{hr,engineering,sales}/` — primary editable sources.
- **10 PDF** companions generated by `scripts/build_pdf_corpus.py` from selected Markdown (same topics, PDF format for page-aware demos).

Manifest: `documents/manifest.json` — each entry has `path`, `title`, `department`, `classification` (`public` | `restricted`).

## Adding documents manually

1. Place file under `documents/<department>/`.
2. Add entry to `manifest.json`.
3. Run `python scripts/ingest.py` from `project/`.

## Admin upload (UI)

- User must have **Admin** role (Bhaskar demo account).
- Accepts `.pdf`, `.md`, `.txt` up to 10 MB.
- Appends manifest entry and runs single-document ingest (Qdrant + BM25).

## Re-ingest when required

Run full `ingest.py` after:

- Changing BM25/Qdrant chunk schema
- Bulk manifest changes
- `build_pdf_corpus.py`

This recreates the Whoosh BM25 index (required when schema fields change).

## Page-aware chunks

- PDFs are parsed **per page**; chunks store `page_start` / `page_end`.
- Markdown files use page `1`.
- Citations and full-document viewer use page metadata for PDFs.
